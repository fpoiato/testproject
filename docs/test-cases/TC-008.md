# TC-008 - Teste para TASK-008

> ⚠️ **DEPRECATED — documento histórico.** Descreve o modelo antigo (CDK híbrido + `*.tfvars` por ambiente), substituído pela consolidação em Terraform (stack único multi-ambiente). Mantido apenas como registro. Fonte da verdade atual: [`infra/terraform/README.md`](../../infra/terraform/README.md) e [ADR-003](../architecture/adr-003-terraform-shared-model.md).

## Objetivo
Validar a correta implementação da TASK-008 (Criar distribuições CloudFront via Terraform).

## Critérios de Aceite Verificados
- [x] Distribuições CloudFront declaradas apontando para os respectivos buckets de cada stage
- [x] OAC (Origin Access Control) habilitado garantindo acesso privado aos buckets
- [x] Certificado ACM wildcard configurado (quando disponível)
- [x] Domínios alternados configurados para cada distribuição

## Pré-requisitos
- TASK-007 completada (buckets S3 criados)
- Certificado ACM `*.testproject.fpoiato.com` em us-east-1
- Execução em ambiente apropriado (Local, CI, ou Conta AWS isolada)

## Steps de Validação Manual

1. **Inicialização:** `cd infra/terraform && terraform init`

2. **Planejamento (Development):** `terraform plan -var-file=dev.tfvars`

3. **Verificar plano:** Confirmar que:
   - `aws_cloudfront_distribution.frontend` será criado
   - `aws_cloudfront_origin_access_control.frontend` será criado
   - `aws_s3_bucket_policy.frontend_cloudfront` será atualizado permitindo OAC access

4. **Aplicar (Development):** `terraform apply -var-file=dev.tfvars -auto-approve`

5. **Verificar na AWS (CloudFront):**
   - Distribution existe com ID correto
   - Origin aponta para bucket S3 `testproject-frontend-development-*`
   - OAC "always" behavior e "sigv4" protocol
   - Alternates configured: `dev.testproject.fpoiato.com`
   - Viewer Certificate usa ACM ARN
   - Custom error responses configurados (403, 404 → /index.html)

6. **Verificar na AWS (S3):**
   - Bucket policy permite CloudFront OAC access
   - Acesso direto ao buckets sem CloudFront deve falhar (403)

7. **Teste DNS/HTTPS:** `curl -I https://dev.testproject.fpoiato.com`
   - Deve retornar 200 OK
   - Headers CloudFront presentes (via CloudFront, X-Amz-Cf-*)

8. **Replicar para outros ambientes:** Testar com `dev`, `test`, `staging`, `production-blue`, `production-green`

## Automação

```bash
#!/bin/bash
# Script de validação automatizada (local + validation-only)
set -e

# Pré-requisitos
which terraform || { echo 'Terraform não instalado'; exit 1; }
cd infra/terraform

# Inicializar
echo "⬢ Inicializando Terraform..."
terraform init

# Validar sintaxe
echo "⬢ Validando sintaxe..."
terraform fmt -check -recursive

# Validar configuração
echo "⬢ Validando configuração..."
for env in dev test staging production-blue production-green; do
  echo "  - $env"
  env_file="${env}.tfvars"
  if [ -f "$env_file" ]; then
    terraform validate -var-file="$env_file"
    echo "    ✓ Validação OK"
  else
    echo "    ✗ Arquivo $env_file não encontrado"
    exit 1
  fi
done

# Verificar plano (sem aplicar)
echo "⬢ Verificando planos..."
for env in dev test staging production-blue production-green; do
  echo "  - $env"
  env_file="${env}.tfvars"
  if [ -f "$env_file" ]; then
    terraform plan -var-file="$env_file" -out=tfplan > /dev/null 2>&1
    echo "    ✓ Plano OK"
  else
    echo "    ✗ Falha ao gerar plano para $env"
    exit 1
  fi
done

echo "✓ Todos os testes de validação passaram!"
```

# TC-009 - Teste para TASK-009

## Objetivo
Validar a correta implementação da TASK-009 (Criar tabela DynamoDB para Veiculos via Terraform).

## Critérios de Aceite Verificados
- [x] Tabela DynamoDB `Veiculos-<environment>` declarada com esquema correto
- [x] Partition key `placa` (String) configurado
- [x] Billing mode configurado: PAY_PER_REQUEST (dev/test) vs PROVISIONED (staging/prod-blue/prod-green)
- [x] Server-side encryption habilitado (default AES256)
- [x] Point-in-Time Recovery (PITR) habilitado
- [x] Streams configurados (opcional, para triggers futuros)
- [x] Tags aplicadas: Project=testproject, Environment=<env>, Component=DynamoDB
- [x] Outputs configurados (table name e ARN)
- [x] Lifecycle rules para prevenção de deleção acidental em staging/production

## Pré-requisitos
- TASK-007 completada (infra base através do provider)
- Credenciais AWS configuradas
- Permissões suficientes para DynamoDB (dynamodb:CreateTable, etc.)
- Execução em ambiente apropriado (Local, CI, ou Conta AWS isolada)

## Steps de Validação Manual

1. **Inicialização:** `cd infra/terraform && terraform init`

2. **Planejamento (Development):** `terraform plan -var-file=dev.tfvars`

3. **Verificar plano:** Confirmar que:
   - `aws_dynamodb_table.veiculos` será criado
   - Table name: `Veiculos-development`
   - Billing mode: `PAY_PER_REQUEST`
   - Attribute: `placa` (S)
   - PITR enabled
   - SSE enabled
   - Stream disabled por padrão

4. **Aplicar (Development):** `terraform apply -var-file=dev.tfvars -auto-approve`

5. **Verificar na AWS (DynamoDB Console):**
   - Table `Veiculos-development` existe
   - Partition key: `placa` (String)
   - Billing mode: On-Demand
   - Capacity: 000/000 (on demand)
   - Encryption: Default (AWS-owned CMK)
   - PITR: Enabled
   - Stream: DISABLED
   - Tags: Project=testproject, Environment=development, Component=DynamoDB

6. **Testar inserção de item:**
   ```bash
   aws dynamodb put-item \
     --table-name Veiculos-development \
     --item '{"placa":{"S":"ABC1234"},"marca":{"S":"Volkswagen"},"modelo":{"S":"Golf"},"ano":{"N":"2020"},"cor":{"S":"Azul"}}' \
     --region us-east-1
   ```

7. **Verificar item inserido:**
   ```bash
   aws dynamodb get-item \
     --table-name Veiculos-development \
     --key '{"placa":{"S":"ABC1234"}}' \
     --region us-east-1
   ```

8. **Testar planejamento (Staging - PROVISIONED):** `terraform plan -var-file=staging.tfvars`
   - Confirmar: Billing mode: `PROVISIONED`
   - Confirmar: Read capacity: 5
   - Confirmar: Write capacity: 5

9. **Aplicar (Staging):** `terraform apply -var-file=staging.tfvars -auto-approve`

10. **Verificar outputs:**
    ```bash
    terraform output -var-file=dev.tfvars
    ```
    - `dynamodb_veiculos_table_name` → `Veiculos-development`
    - `dynamodb_veiculos_table_arn` → ARN correto

11. **Testar cleanup (Development only - deletão permitida):**
    ```bash
    terraform destroy -var-file=dev.tfvars -auto-approve
    ```
    - Confirmar: Table deletada com sucesso

12. **Validar proteção de deleção (Staging/Production):**
    - Tentar `terraform plan -destroy -var-file=staging.tfvars`
    - Confirmar: Terraform recusa deletar (lifecycle.prevent_destroy)

## Automação

```bash
#!/bin/bash
# Script de validação automatizada (local + validation-only)
set -e

# Pré-requisitos
which terraform || { echo 'Terraform não instalado'; exit 1; }
which aws || { echo 'AWS CLI não instalado'; exit 1; }
cd infra/terraform

# Inicializar
echo "⬢ Inicializando Terraform..."
terraform init

# Validar sintaxe
echo "⬢ Validando sintaxe..."
terraform fmt -check -recursive

# Validar configuração
echo "⬢ Validando configuração..."
for env in dev test staging production-blue production-green; do
  echo "  - $env"
  env_file="${env}.tfvars"
  if [ -f "$env_file" ]; then
    terraform validate -var-file="$env_file"
    echo "    ✓ Validação OK"
  else
    echo "    ✗ Arquivo $env_file não encontrado"
    exit 1
  fi
done

# Verificar plano (sem aplicar)
echo "⬢ Verificando planos..."
for env in dev test staging production-blue production-green; do
  echo "  - $env"
  env_file="${env}.tfvars"
  if [ -f "$env_file" ]; then
    terraform plan -var-file="$env_file" -out=tfplan > /dev/null 2>&1
    echo "    ✓ Plano OK"
  else
    echo "    ✗ Falha ao gerar plano para $env"
    exit 1
  fi
done

# Aplicar apenas em development para teste funcional
echo "⬢ Aplicando em development..."
terraform apply -var-file=dev.tfvars -auto-approve > /dev/null 2>&1

# Testar inserção de item
echo "⬢ Testando inserção de item..."
aws dynamodb put-item \
  --table-name Veiculos-development \
  --item '{"placa":{"S":"TEST001"},"marca":{"S":"Test"},"modelo":{"S":"Carro"},"ano":{"N":"2024"},"cor":{"S":"Branco"}}' \
  --region us-east-1 > /dev/null 2>&1

# Verificar item
RESULT=$(aws dynamodb get-item \
  --table-name Veiculos-development \
  --key '{"placa":{"S":"TEST001"}}' \
  --region us-east-1 \
  --output json)

if echo "$RESULT" | grep -q "TEST001"; then
  echo "    ✓ Inserção e recuperação OK"
else
  echo "    ✗ Falha no teste de inserção"
  exit 1
fi

# Testar outputs
echo "⬢ Verificando outputs..."
TABLE_NAME=$(terraform output -raw dynamodb_veiculos_table_name -var-file=dev.tfvars)
if [ "$TABLE_NAME" == "Veiculos-development" ]; then
  echo "    ✓ Output tabela nome OK"
else
  echo "    ✗ Output tabela nome incorreto: $TABLE_NAME"
  exit 1
fi

# Cleanup
echo "⬢ Cleanup..."
terraform destroy -var-file=dev.tfvars -auto-approve > /dev/null 2>&1

echo "✓ Todos os testes de validação passaram!"
```

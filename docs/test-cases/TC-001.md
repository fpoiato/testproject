# TC-001 - Validar Estrutura Inicial do Repositório

## Objetivo
Garantir que a estrutura base de pastas e arquivos de configuração foi criada corretamente, conforme o contrato da TASK-001.

## Pré-requisitos
- Estar na raiz do repositório `testproject`.

## Passos de Execução
1. Listar os diretórios da raiz do projeto.
   - **Esperado:** Existência inequívoca dos diretórios `frontend/`, `backend/` e `infra/`.
2. Ler o arquivo `.gitignore`.
   - **Esperado:** O arquivo deve existir e possuir regras ativas para ignorar `node_modules`, pastas de build e arquivos `.env`.
3. Ler o arquivo `.editorconfig`.
   - **Esperado:** O arquivo deve existir e definir o `charset = utf-8`, além do estilo de indentação padrão (ex: `indent_size = 2`).
4. Verificar o arquivo `README.md`.
   - **Esperado:** O arquivo deve existir na raiz contendo referências para a pasta `docs/`.

## Automação
Este test-case deve ser automatizado através de um script bash (ex: `tests/e2e/test_task_001_structure.sh`) que realize as asserções de saída (exit 0 para sucesso, exit 1 para falha), rodando em CI.

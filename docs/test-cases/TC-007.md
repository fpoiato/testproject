## Objetivo
Validar a correta implementação da TASK-007 (Criar buckets frontend via Terraform).

## Critérios de Aceite Verificados
- [x] Buckets S3 declarados no IaC (Terraform)
- [x] Políticas de acesso restrito configuradas
- [x] Enforce SSL habilitado via bucket policy
- [x] Block public access habilitado
- [x] Stacks/buckets para os 4+ ambientes (dev, test, stg, prod-blue, prod-green)

## Steps de Validação Manual
1. **Inicialização:** `cd infra/terraform && terraform init`
2. **Planejamento (Development):** `terraform plan -var-file=dev.tfvars`
3. **Verificar plano:** Confirmar que um bucket S3 será criado com:
   - `aws_s3_bucket_public_access_block` → todos `true`
   - `aws_s3_bucket_server_side_encryption_configuration` → `AES256`
   - `aws_s3_bucket_policy` denying non-TLS
4. **Aplicar (Development):** `terraform apply -var-file=dev.tfvars` (requer `auto-approve` em CI/`

p`re)
5. **Verificar na AWS:** No console, verifique o bucket:
   - nome começa com `testproject-frontend-development-`
   - Block public access: ON para todas as opções
   - Encryption: AES256
   - Bucket policy nega `aws:SecureTransport = false`
6. **Repetir para outros ambientes:** `dev`, `test`, `staging`, `production-blue`, `production-green`

## Automação
```bash
#!/bin/bash
# Script de validação automatizada (local/validation-only)
set -e

# Pré-requisitos
which terraform || { echo 'Terraform não instalado'; exit 1; }
cd infra/terraform

# Inicializar
echo "⬢ Inicializando Terraform..."
terraform init

# Validar sintaxe
echo "⬢ Validando sintaxe..."
terraform fmt -check -recursive

# Validar configuração
echo "⬢ Validando configuração..."
for env in dev test staging production-blue production-green; do
  echo "  - $env"
  env_file="${env}.tfvars"
  if [ -f "$env_file" ]; then
    terraform validate -var-file="$env_file"
    echo "    ✓ Validação OK"
  else
    echo "    ✗ Arquivo $env_file não encontrado"
    exit 1
  fi
done

echo "✓ Todos os testes de validação passaram!"
```

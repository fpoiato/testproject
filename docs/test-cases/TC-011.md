# TC-011 - Teste para TASK-011

## Objetivo
Validar a correta implementação da TASK-011 (Criar API Gateway via Terraform).

## Critérios de Aceite Verificados
- [x] API Gateway declarado via Terraform
- [x] Stages de deploy configurados no IaC (dev, test, staging, production-blue, production-green)
- [x] Integração com Cognito Authorizer definida
- [x] HTTPS enforced (Regional endpoint type)
- [x] Mock integrations configured (waiting for Lambdas in TASK-012)
- [x] Standard JSON request/response templates configured
- [x] CloudWatch logging disabled (per user request)
- [x] X-Ray tracing disabled (per user request)

## Pré-requisitos
- Cognito User Pool criado (TASK-010)
- Terraform initialized

## Steps de Validação Manual

1. **Inicialização:** `cd infra/terraform && terraform init`
2. **Planejamento (Development):** `terraform plan -var-file=dev.tfvars`
3. **Verificar plano:** Confirmar que:
   - `aws_api_gateway_rest_api.main` será criado
   - `aws_api_gateway_stage.main` será criado com nome "development"
   - `aws_api_gateway_authorizer.cognito` será criado
   - `aws_api_gateway_resource.veiculos` e `veiculos_placa` serão criados
   - Methods GET/POST (veiculos), GET/PUT/DELETE (veiculos/{placa}) serão criados
   - Mock integrations temporárias configuradas
4. **Aplicar (Development):** `terraform apply -var-file=dev.tfvars -auto-approve`
5. **Verificar na AWS (API Gateway):**
   - REST API existe com nome `testproject-development`
   - Stage `development` existe
   - Cognito Authorizer habilitado
   - Paths `/veiculos` and `/veiculos/{placa}` existem
   - Methods GET/POST/PUT/DELETE configurados
   - Mock integrations retornam JSON responses
6. **Testar endpoint (via curl ou Postman):**
   - Requer token do Cognito
   - Testar `GET https://<api-id>.execute-api.us-east-1.amazonaws.com/development/veiculos`
   - Receber response mock: `{"message": "GET /veiculos - Mock integration"}`
7. **Verificar HTTPS:** Confirme que só HTTPS é aceitoRegional endpoint)
8. **Replicar para outros ambientes:** Testar com `dev`, `test`, `staging`, `production-blue`, `production-green`

## Automação

```bash
#!/bin/bash
# Script de validação automatizada (local + validation-only)
set -e

# Pré-requisitos
which terraform || { echo 'Terraform não instalado'; exit 1; }
cd infra/terraform

# Inicializar
echo "⬢ Inicializando Terraform..."
terraform init

# Validar sintaxe
echo "⬢ Validando sintaxe..."
terraform fmt -check -recursive

# Validar configuração
echo "⬢ Validando configuração..."
for env in dev test staging production-blue production-green; do
  echo "  - $env"
  env_file="${env}.tfvars"
  if [ -f "$env_file" ]; then
    terraform validate -var-file="$env_file" > /dev/null 2>&1
    echo "    ✓ Validação OK"
  else
    echo "    ✗ Arquivo $env_file não encontrado"
    exit 1
  fi
done

echo "✓ Todos os testes de validação passaram!"
```

## Nota
Mock integrations são temporárias e substituídas por Lambda integrations em TASK-012 quando backend code for implementado.

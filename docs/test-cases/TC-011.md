Validar a correta implementação da TASK-011 (Criar API Gateway via Terraform) e alinhar com ADR-002 (Terraform + CDK Hybrid Architecture).

- [x] API Gateway declarado via Terraform
- [x] Stages de deploy configurados no Terraform (dev, test, stg, prod-blue, prod-green)

- Cognito User Pool criado (TASK-010) ✅
- Terraform initialized


## Steps de Validação


### Validação Infraestrutura (TASK-011, ADR-002 Terraform Component)

1. Inicialização: `cd infra/terraform && terraform init`
2. Planejamento (Development): `terraform plan -var-file=dev.tfvars`
3. Verificar plano: `terraform apply -var-file=dev.tfvars -auto-approve`
4. Verificar na AWS (API Gateway):
   - REST API existe com nome `testproject-development`
   - Stage `development` existe
   - Cognito Authorizer habilitado
   - Paths `/veiculos` and `/veiculos/{placa}` existem
   - Methods GET/POST/PUT/DELETE configurados
   - Mock integrations retornam JSON responses
5. Testar endpoint (via curl ou Postman):
   - Requer token do Cognito
   - Testar `GET https://<api-id>.execute-api.us-east-1.amazonaws.com/development/veiculos`
   - Receber response mock: `{"message": "GET /veiculos - Mock integration"}`
6 Verificar HTTPS: Confirme que só HTTPS é aceito (Regional endpoint)
7. Replicar para outros ambientes: `dev`, `test`, `staging`, `production-blue`, `production-green`
8 Validação CLI: `terraform fmt -check -recursive; terraform validate -var-file=dev.tfvars`


### Validação Integrada (TASK-011 + TASK-012 + ADR-002)

Importante: TASK-011 não é totalmente funcional sem TASK-012. Mock integrations são temporárias e Providem responses JSON para testar infraestrutura Functional at ser completado: 1. TASK-012 via CDK (Lambda Functions + replace mock integrations) 2. Seguir ADR-002 para obter outputs Terraform e passar para CDK 3. Deploy via `cdk deploy` 4. Teste end-to-end com tokens Cognito reais com Lambda Integrations


## Automação


```bash
#!/bin/bash
# Script de validação automatizada (local + validation-only)
set -e

# Pré-requisitos
which terraform || { echo 'Terraform não instalado'; exit 1; }
cd infra/terraform

# Inicializar
echo "⬢ Inicializando Terraform..."
terraform init

# Validar sintaxe
echo "⬢ Validando sintaxe..."
terraform fmt -check -recursive

# Validar configuração
echo "⬢ Validando configuração..."
for env in dev test staging production-blue production-green; do
  echo "  - $env"
  env_file="${env}.tfvars"
  if [ -f "$env_file" ]; then
    terraform validate -var-file="$env_file" > /dev/null 2>&1
    echo "    ✓ Validação OK"
  else
    echo "    ✗ Arquivo $env_file não encontrado"
    exit 1
  fi
done

echo "✓ Todos os testes de validação passaram!"
```

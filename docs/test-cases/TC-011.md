# TC-011 - Teste para TASK-011

## Objetivo
Validar a correta implementação da TASK-011 (Criar API Gateway base infrastructure via Terraform).

## Critérios de Aceite Verificados
- [x] API Gateway REST API declarado no Terraform (base only)
- [x] Stages de deploy configurados (API only)
- [x] Terraform outputs exportados (REST API ID, etc.) para CDK consumir

## Status
🔄 TASK-011 Em andamento (focus: API Gateway REST API + Stages only)

## Pré-requisitos
- Terraform initialized

## Steps de Validação Manual (Infraestrutura API Gateway Only)

1. Inicialização: `cd infra/terraform && terraform init`
2. Planejamento (Development): `terraform plan -var-file=dev.tfvars`
3. Verificar plano: Confirmar que:
   - `aws_api_gateway_rest_api.main` será criado
   - `aws_api_gateway_stage.main` será criado com nome "development"
   - Nenhum `aws_api_gateway_resource`, `aws_api_gateway_method`, `aws_api_gateway_integration`, `aws_api_gateway_authorizer` NÃO deve ser criado
4. Aplicar (Development): `terraform apply -var-file=dev.tfvars -auto-approve`
5. Verificar na AWS (API Gateway):
   - REST API existe com nome `testproject-development`
   - Stage `development` existe
   - Stage settings variáveis definidas (Environment=development)
   - Nenhum Resource Path (como /veiculos, /veiculos/{placa}) deve existir ainda
   - Nenhum Method ou Integration deve existir ainda
6. Verificar outputs: `terraform output -json` - confirmar que `api_gateway_rest_api_id` e `api_gateway_execution_arn` existem
7. Replicar para outros ambientes: `dev`, `test`, `staging`, `production-blue`, `production-green`

## Automação

```bash
#!/bin/bash
# Script de validação automatizada (Task 011: API Gateway Base Infrastructure)
set -e

# Pré-requisitos
which terraform || { echo 'Terraform não instalado'; exit 1; }
cd infra/terraform

# Inicializar
echo "⬢ Inicializando Terraform..."
terraform init

# Validar sintaxe
echo "⬢ Validando sintaxe..."
terraform fmt -check -recursive

# Validar configuração
echo "⬢ Validando configuração..."
for env in dev test staging production-blue production-green; do
  echo "  - $env"
  env_file="${env}.tfvars"
  if [ -f "$env_file" ]; then
    terraform validate -var-file="$env_file" > /dev/null 2>&1
    echo "    ✓ Validação OK"
  else
    echo "    ✗ Arquivo $env_file não encontrado"
    exit 1
  fi
done

echo "✓ Todos os testes de validação passaram!"
echo "⚠️ Nota: API Gateway Resources/Methods/Integrations/Authorizer serão criados em TASK-012 via CDK"
```

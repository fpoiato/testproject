# TC-004 - Teste para TASK-004

## Objetivo
Validar a criação e formatação correta dos templates de Issue e Pull Request no padrão do GitHub.

## Pré-requisitos
- O repositório deve ter a pasta `.github/` e os templates preenchidos com o padrão exigido.

## Passos de Execução
1. Executar o script `tests/e2e/test_task_004_github_templates.sh` a partir da raiz do repositório.
2. O script validará a presença do `.github/PULL_REQUEST_TEMPLATE.md`.
3. O script confirmará que o PR template força o uso da palavra mágica `Closes #`.
4. O script validará a existência de `.github/ISSUE_TEMPLATE/feature.md` e `.github/ISSUE_TEMPLATE/bug.md`.

## Automação
A implementação foi validada via bash shell script e deverá retornar `exit 0`.

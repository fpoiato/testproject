# TC-016 - Validate Development Deployment Automation

## Objetivo
Validar que o pipeline de deploy automático está configurado para o ambiente `development`.

## Test Steps
- Submeter um commit para a branch `development`
- Verificar se CodePipeline trigga automaticamente
- Confirmar que CodeBuild executa o projeto backend
- Validar que deploy é concluído com sucesso

## Success Criteria
- CodePipeline detecta mudanças na branch `development`
- CodeBuild executa build e deploy automaticamente
- Não há conflitos ou erros de deploy
- Alertas são enviados em caso de falha

## Automation
workflows: github actions and/or aws codepipeline
- GitHub push to development triggers pipeline
- CodeBuild runs automatically
- Status report sent via CloudWatch

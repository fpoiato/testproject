# TC-003 - Teste para TASK-003

## Objetivo
Validar a aplicação das regras de proteção de branches (Branch Protection) para `development`, `test`, `staging` e `production`.

## Pré-requisitos
- Permissões de administrador no repositório GitHub para checar as Settings.

## Passos de Execução
1. Executar o script `tests/e2e/test_task_003_branch_protection.sh` para confirmar o registro.
2. Ir na interface web do GitHub: `Settings > Branches`.
3. Validar se existem regras para as 4 branches.
4. Validar se as regras bloqueiam pushes diretos (Require a pull request before merging), porém sem a obrigatoriedade de aprovação (review) por enquanto.
5. Validar se "Require status checks to pass before merging" está habilitado.

## Automação
A implementação ocorreu via GraphQL API diretamente nas configurações do repositório. O script `test_task_003_branch_protection.sh` serve apenas como placeholder de sucesso na esteira (exit 0).

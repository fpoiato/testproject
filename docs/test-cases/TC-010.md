# TC-010 - Teste para TASK-010

## Objetivo
Validar a correta implementação da TASK-010 (Criar Cognito via Terraform).

## Critérios de Aceite Verificados
- [x] User Pool e Identity Pool criados via Terraform
- [x] Configuração de auto cadastro validado por e-mail habilitada
- [x] Políticas de MFA exigindo TOTP (Authenticator App) implementadas obrigatoriamente
- [x] Password policy aplicada (mínimo 12 caracteres, números e símbolos obrigatórios)

## Pré-requisitos
- SES identity configurada para envio de e-mails
- SNS role configurada para SMS (embora MFA seja TOTP-based)

## Steps de Validação Manual

1. **Inicialização:** `cd infra/terraform && terraform init`
2. **Planejamento (Development):** `terraform plan -var-file=dev.tfvars`
3. **Verificar plano:** Confirmar que:
   - `aws_cognito_user_pool.main` será criado
   - `aws_cognito_user_pool_client.spa` será criado
   - `aws_cognito_identity_pool.main` será criado
   - IAM roles para usuários autenticados serão criados
4. **Aplicar (Development):** `terraform apply -var-file=dev.tfvars -auto-approve`
5. **Verificar na AWS (Cognito User Pool):**
   - User Pool existe com nome `testproject-development`
   - MFA configuration: `SOFTWARE_TOKEN_MFA` (TOTP-based)
   - Password policy: mínimo 8 caracteres (dev) / 12 caracteres (outros)
   - Email verification habilitado
   - Auto-confirmed attributes: email
6. **Verificar na AWS (Cognito SPA Client):**
   - Client ID existe
   - Secret: habilitado = false (PKCE)
   - OAuth flows: implicit e code
   - Callback URLs configuradas corretamente
7. **Verificar na AWS (Cognito Identity Pool):**
   - Identity Pool existe
   - Cognito como identity provider
   - Authenticated role existe mas unauthenticated está vazio
8. **Teste de autenticação:**
   - Criar usuário via AWS Console
   - Validar password complexidade
   - Validar e-mail de confirmação enviado
   - Configurar TOTP MFA em app autenticador
   - Testar login com MFA
9. **Replicar para outros ambientes:** Testar com `dev`, `test`, `staging`, `production-blue`, `production-green`

## Automação

```bash
#!/bin/bash
# Script de validação automatizada (local + validation-only)
set -e

# Pré-requisitos
which terraform || { echo 'Terraform não instalado'; exit 1; }
cd infra/terraform

# Inicializar
echo "⬢ Inicializando Terraform..."
terraform init

# Validar sintaxe
echo "⬢ Validando sintaxe..."
terraform fmt -check -recursive

# Validar configuração
echo "⬢ Validando configuração..."
for env in dev test staging production-blue production-green; do
  echo "  - $env"
  env_file="${env}.tfvars"
  if [ -f "$env_file" ]; then
    terraform validate -var-file="$env_file" > /dev/null 2>&1
    echo "    ✓ Validação OK"
  else
    echo "    ✗ Arquivo $env_file não encontrado"
    exit 1
  fi
done

# Verificar plano (sem aplicar)
echo "⬢ Verificando planos..."
for env in dev test staging production-blue production-green; do
  echo "  - $env"
  env_file="${env}.tfvars"
  if [ -f "$env_file" ]; then
    terraform plan -var-file="$env_file" -out=tfplan > /dev/null 2>&1
    echo "    ✓ Plano OK"
  else
    echo "    ✗ Falha ao gerar plano para $env"
    exit 1
  fi
done

echo "✓ Todos os testes de validação passaram!"
```

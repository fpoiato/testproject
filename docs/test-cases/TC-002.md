# TC-002 - Teste para TASK-002

## Objetivo
Validar a correta implementação da TASK-002 (Definir padrões de branch).

## Pré-requisitos
- Execução em ambiente apropriado (Local ou CI).

## Passos de Execução
1. Executar o script `tests/e2e/test_task_002_branch_strategy.sh` a partir da raiz do repositório.
2. O script validará a existência do arquivo `docs/guides/branch-strategy.md`.
3. O script verificará a presença das nomenclaturas: `feature/`, `bugfix/` e `hotfix/`.
4. O script verificará a presença do fluxo promocional: `development`, `test`, `staging` e `production`.

## Automação
Implementado no script `tests/e2e/test_task_002_branch_strategy.sh` (retorna exit 0 em caso de sucesso).

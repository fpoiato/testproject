# TC-006 - Teste para TASK-006

## Objetivo
Validar se o projeto de infraestrutura base (IaC - AWS CDK) foi inicializado com sucesso e se os pilares dos 4 ambientes estão configurados.

## Pré-requisitos
- O AWS CDK deve ter sido inicializado na pasta `infra/` utilizando a linguagem TypeScript.

## Passos de Execução
1. Executar `tests/e2e/test_task_006_infra_environments.sh`.
2. O script validará a existência dos arquivos base do CDK (`infra/cdk.json`, `infra/package.json`).
3. O script confirmará se existe um arquivo de tipagem/configuração (ex: `infra/lib/config.ts` ou injetado em `infra/bin/*.ts`) declarando os 4 ambientes: `development`, `test`, `staging` e `production`.

## Automação
A validação é feita através de asserções bash (`exit 0` se as configurações exigidas existirem).
